# Apple TV 17.0.3: патч для региона `rs` на LG webOS

Этот офлайн-инструмент проверяет оригинальные `main.js` и `app.js` по SHA-256 и создаёт две локальные изменённые копии в новой папке. Он не связывается с телевизором, Apple, LG или сетью. В репозитории нет полных файлов Apple JavaScript, прошивки, бинарных файлов, ключей или данных аккаунта. Изменённые копии создаются только локально из ваших оригинальных файлов.

Совместимость ограничена точными входными SHA-256 из [patches.json](patches.json), соответствующими Apple TV 17.0.3 на проверенном устройстве. При любом несовпадении программа прекращает работу. Генератор не меняет прошивку, исполняемый файл, подписи, DRM, установленное приложение на телевизоре, настройки магазина или автоматические обновления Store. Обновление приложения Apple TV может заменить патч или сделать его несовместимым; после любого обновления эти файлы нельзя использовать повторно без новой проверки совместимости. Постоянная замена обоих файлов проверена после обычной перезагрузки одного устройства; холодное отключение и повторное включение питания отдельно не проверялось. Подробности — в [VALIDATION-RU.md](VALIDATION-RU.md), на русском. Сам генератор не проверяет поведение приложения во время работы.

Патч исправляет региональные параметры сервиса для региона `rs` и отключает путь автоматического обновления JSUpdater для этой точной версии. Автоматические обновления Store остаются включёнными. Это не обещание постоянной совместимости, успешного входа или воспроизведения DRM-защищённого видео.

## Обязательное условие: root-доступ на телевизоре

До применения изменений на телевизоре необходимо уже иметь проверенный root-доступ. Локальному офлайн-генератору на компьютере root не нужен; запись файлов приложения и переход на постоянный overlay на телевизоре требуют root.

На проверенном устройстве использовался [SlopBro автора throwaway96](https://github.com/throwaway96/slopbro), в [исторически зафиксированной ревизии `21023d56ca424607bb03d2939609cc658c655fc7`](https://github.com/throwaway96/slopbro/tree/21023d56ca424607bb03d2939609cc658c655fc7), который устанавливает [webOS Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel). SlopBro — использованная root-утилита; Homebrew Channel — связанный инструмент, устанавливаемый этой процедурой.

Перед выбором root-метода проверьте в актуальной документации автора поддержку точной модели, регионального суффикса и версии прошивки. Это не универсальный метод для всех телевизоров LG. Совпадение хешей Apple TV JS не подтверждает совместимость root-метода с прошивкой.

Root и постоянные изменения несут риск потери данных или неработоспособности устройства. Восстановление заводской прошивки через USB не гарантировано и не должно считаться надёжным планом восстановления. Скрипты этого патча не выполняют рутование, не загружают и не запускают SlopBro и не устанавливают Homebrew Channel; подготовка root-доступа — отдельный этап.

## Использование

Нужны Python 3.9+ и каталог с оригинальными файлами `main.js` и `app.js`, полученными законным способом из собственного телевизора или резервной копии.

```sh
python3 apply_patch.py --input-dir /path/to/your/original-js --output-dir /path/to/new/local-candidates
```

Каталог результата должен отсутствовать. Программа сначала проверяет оба входных файла и собирает оба результата в памяти. Только после проверки обеих ожидаемых выходных SHA-256 она создаёт новый каталог и записывает туда `main.js`, `app.js` и `SHA256SUMS.json`. Существующую папку результата она не перезаписывает. Храните созданные файлы локально и не добавляйте их в Git.

`patches.json` хранит только исходные и целевые SHA-256, смещения, длины удаляемых участков, SHA-256 удалённых байтов и Base64 новых байтов. В нём нет исходных текстовых якорей производителя, полных Apple-файлов или окружающего исходного контекста. Применение всегда требует оригиналы с точно совпадающими SHA-256.

## Проверка

Следующая команда использует только синтетические тестовые данные:

```sh
python3 -m unittest discover -s tests
```

Ни тесты, ни генератор не меняют телевизор. Проверка реальных оригиналов подтверждает только побайтовое совпадение результата с заранее подготовленной изменённой копией; она не доказывает поведение приложения во время работы, вход или воспроизведение.
