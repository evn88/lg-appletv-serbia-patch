# Apple TV 17.0.3: патч для региона `rs` на LG webOS

Этот инструмент офлайн проверяет оригинальные `main.js` и `app.js` по SHA-256 и создает две локальные измененные копии в новой папке. Он не связывается с телевизором, Apple, LG или сетью. В репозитории нет полных файлов Apple JavaScript, прошивки, бинарных файлов, ключей или данных аккаунта. Кандидаты создаются только у вас локально из ваших оригинальных файлов.

Совместимость ограничена точными входными SHA-256 из `patches.json` (Apple TV 17.0.3 на проверенном устройстве). При любом несовпадении программа прекращает работу. Она не меняет прошивку, бинарник, подпись, DRM, приложение на телевизоре, настройки магазина или автоматические обновления Store. Обновление Apple может заменить патч или сделать его несовместимым; после любого обновления эти файлы нельзя переиспользовать без новой проверки. Постоянная пара проверена после обычного reboot на одном устройстве; холодное отключение питания отдельно не проверено. Подробности в `VALIDATION-RU.md`. Сам генератор runtimeпроверок не выполняет.

Патч исправляет региональные параметры сервиса для региона `rs` и блокирует путь автообновления JSUpdater для зафиксированной версии. Автоматические обновления Store остаются включены. Это не обещание постоянной совместимости, входа или воспроизведения DRM-защищенного видео.

## Использование

Нужен Python 3.9+ и каталог с оригинальными файлами `main.js` и `app.js`, полученными законным способом из собственного телевизора или резервной копии.

```sh
python3 apply_patch.py --input-dir /path/to/your/original-js --output-dir /path/to/new/local-candidates
```

Каталог результата должен отсутствовать. Программа сначала проверит оба входных файла и соберет оба результата в памяти. Только после успешной проверки обеих целевых SHA она создаст новый каталог и запишет туда `main.js`, `app.js` и `SHA256SUMS.json`. Существующую папку результата она не перезаписывает. Храните созданные файлы локально и не добавляйте их в Git.

`patches.json` хранит только базовую/целевую SHA, смещения, длины удаляемых участков, SHA удаленных байтов и Base64 новых байтов. В нем нет исходных vendor-строк, полных Apple-файлов или контекстных фрагментов. Применение всегда требует оригиналы с точно совпадающими SHA.

## Проверка

Только синтетические тестовые строки:

```sh
python3 -m unittest discover -s tests
```

Ни тесты, ни генератор не меняют телевизор. Проверка реальных оригиналов подтверждает только байтовое совпадение результата с заранее подготовленным кандидатом и не доказывает runtime-поведение, вход или воспроизведение.

## Лицензия и происхождение

Исходная идея и региональная задача связаны с проектом [mircea1223/lg-appletv-romania](https://github.com/mircea1223/lg-appletv-romania/tree/a0fdd116310305d2d85f14bcdbd321d31b13bd28). Его инструмент содержит SPDX `AGPL-3.0-or-later`; здесь сохранены атрибуция и SPDX для генератора и метаданных патча. Сам upstream Python-код и его minified Apple anchors сюда не копировались. Полный текст GNU AGPL версии 3 сохранён в `COPYING`. Применяется SPDX `AGPL-3.0-or-later`; происхождение изменений описано в `PROVENANCE.md`.

Защитный сценарий перехода с прежней локальной bindустановки находится в `tv-migration/`. Его предварительные условия и ограничения описаны отдельно; универсального установщика и полной прошивки этот пакет не содержит.

После последней постоянной установки и reboot повторное воспроизведение ещё ожидает проверки владельцем. Подтверждены сохранённые JS, штатный запуск Apple TV и сохранность Home v6.
