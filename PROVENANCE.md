# Provenance and release status

This package contains a locally authored offline byte-offset generator and the six minimal edits adapted for the tested Apple TV 17.0.3 JavaScript resources. Its patch data was derived from the corresponding original files and the verified modified candidates; those full files are not distributed. Only minimal byte-level differences were serialized: original offsets, deletion lengths, SHA-256 hashes of removed bytes, and Base64 for inserted bytes. No before-text, context snippets, full vendor files, candidate files, firmware, backup, or device log is included.

Local derivation validated the full result byte-for-byte against the two clean candidates. The base fingerprints are `d9c95106c263090df8b893d34f8c8f261b52d722bf7fd63923e9ed38b31be9c8` (`main.js`) and `a4071bd6f36d3be07093d9dabd05b28d69713d74ceb09743e9a0340578b605f8` (`app.js`). Target fingerprints are `2f406936ba4c05b43d7709b33f7fe6f7fdc5f454eff741a1ffea023f9b6433c5` and `b20ce8baa307fad236629c177ae83a1271287cc87df7f3fc9fd292762680f1cc`, respectively. Each patch refuses a different base or target.

The related upstream project is [mircea1223/lg-appletv-romania at commit `a0fdd116310305d2d85f14bcdbd321d31b13bd28`](https://github.com/mircea1223/lg-appletv-romania/tree/a0fdd116310305d2d85f14bcdbd321d31b13bd28).
